# wf_decrypt
弹射世界数据包解密脚本
## 1. 环境要求
安装Python
## 2. 文件依赖
以下文件都应在脚本同目录
- **CodePath.txt**：脚本依赖此文件运行，请与脚本放在同目录。
- **Bundle数据包**：bundle\production，来自APK/assets/bundle.zip
- **Download数据包**：download\production，来自root/data/data/包名/，需要权限获取，所以普遍的做法是对CDN解压模拟下载生成的数据，可以使用wf_cdn_extract.py。
## 3. 如何使用
双击脚本打开会显示菜单：
1. **路径还原**：读取**CodePath.txt**和**AssetPath.txt**，还原文件哈希名至明文原路径。
2. **解密至游戏格式**（png，mp3，deflate）：解密各格式文件，这将会是单机版读取的格式。
3. **解密至可读格式**（amf3>json，orderedmap>csv）：格式转换，主要方便制作游戏MOD补丁，也可用于查看游戏数据。
4. **路径拼接>AssetPath.txt**：此步骤是脚本的核心，将游戏实际使用的路径拼接后输出至此文件。
5. **循环运行1-4**：没有**AssetPath.txt**的情况下脚本需要循环1-4步骤逐步展开，输入5即可自动开始解密。
6. **Unmapped处理**：游戏实际使用的文件基本被以上步骤处理完了，但数据包实际有更多旧文件和跨服文件，这一步主要对无路径文件做路径以外的解密，你可以自己编写**OldPath.txt**对这些文件做路径还原，这主要是为了区别游戏未使用的文件。
s. **切换模式**：脚本默认是解密模式，通过切换为加密模式，可以将文件重新打包为数据包。
## 4. 脚本输出
脚本应该会生成以下文件：
- **intermediate文件夹**：解密数据文件的输出目录。
- **Unmapped文件夹**：仅在运行步骤6时输出的目录。
- **Encrypted**：加密模式步骤3输出的目录。
- **.wf_record.pkl**：脚本的进度记录，仅在重新解密时需要删除，请保留此文件以免丢失解密进度。
- **AssetPath.txt**：脚本拼接的文件原路径，你可以将其复制到不同服务器或不同版本的数据包并运行解密脚本。
## 4. 其它
理论上脚本已支持所有服务器数据包，但如上所述，数据包实际存有更多未使用的文件，要进一步处理这些文件可能需要旧版本的数据包，如果有**台服数据包**或**日服/国服的旧版本数据包**请发给我。
